A simpler end to the week.

  1. Add your projects. Save a name, project code and task code in Projects.
  2. Build your week. Pick projects from the dropdown and enter hours under Monday–Friday. Today is highlighted.
  3. Keep going. Changes save immediately. Reopen the app to start on the current week, or use the arrows to revisit an earlier one.
  4. Copy on Friday. Export this week for Oracle, and keep a full backup regularly.

Changing a project in the library affects new rows. Existing weeks keep the project name and codes used when the row was created. To change an existing row, choose its project again.
